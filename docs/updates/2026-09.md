With mcp 1.30.0: 14 passed in `test/test_mcp_server`, full suite 361 passed, 2 skipped. With mcp 2.2.0 in a scratch venv the round trip and the existing `build_server` test fail, so the tests catch the regression.
- **Local env**: installed `mcp` 1.30.0 into `.venv` (no repo change).
- **Files**: `pyproject.toml`, `.github/workflows/ci.yml`, `test/test_mcp_server/test_server.py`, `architecture.md` §3.
